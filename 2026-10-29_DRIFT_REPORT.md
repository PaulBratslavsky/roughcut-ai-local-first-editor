# Drift report — `core/` contracts (2026-10-29)

EGM drift review of the seven `README.md` contracts generated by
`/egm:egm-bootstrap core`, each checked against the current source by a fresh
reviewer. Only divergences are listed; line references are to the README and
the source at the time of the review.

## core/README.md

- **Embeddings fallback is wrong.** The README says demo mode and `Editor::test_instance` fall back to `MockEmbedder`. `Editor::embedder()` always builds an `OllamaEmbedder` from preferences (`engine/mod.rs:176-182`), and `test_instance` never installs `MockEmbedder` (`engine/mod.rs:134-148`). It is reachable only through `set_embedder_for_tests` (`tests/e2e.rs:246,431,452,595`). With no embedding server, indexing is skipped and search falls back to BM25 (`engine/semantic.rs:74-77,224-231`).
- **"Runs without whisper" holds only when ffmpeg is also missing.** Demo mode means `FABLE_DEMO=1` or no ffmpeg/ffprobe (`capabilities.rs:34,50-52`). With ffmpeg present but no whisper-cli, `AutoTranscriber` returns `Unavailable` (`adapters/transcribe.rs:344-361`).
- **Not every AI feature falls back to heuristics.** `story_edit` with no model server and no target returns `Unavailable` (`story.rs:593,620-622`).
- **Adapter traits are not the only route out of the process.** Face finding and capture are free functions (`adapters/face.rs`, `adapters/record.rs`). Model servers are probed with `reqwest` directly (`setup.rs:150-172`, `llm_runtime.rs:268-279`). Ollama and llama-server are spawned directly (`llm_runtime.rs:83,253`). ffmpeg is also reached through `load_raw_peaks`, `ensure_playable_copy`, and `record::combine_recordings` (`adapters/video.rs:473,638`; `engine/media.rs:163`).
- **Not every operation is a registry row, and `dispatch` is not the only entry point.** The Tauri app calls `editor.export` for `send_to_resolve` (`app/src-tauri/src/lib.rs:119-130`) and `editor.attach_screen_media` directly (`lib.rs:174-182`). Recording, setup/downloads, the LLM runtime, PTY, and Resolve are Tauri commands only (`lib.rs:72-107,150-278`).
- **Not all journaled edits are frame-snapped.** `normalize_op` snaps only `CutRange`, `RestoreRange`, `TrimClip`, and `SplitClip` (`engine/edits.rs:583-604`). `CutSegments`/`RestoreSegments` use raw segment times (`edits.rs:645-659`) and `RoughCut` uses raw detected ranges (`edits.rs:703-709`).
- **"Frame-exact inside" overstates the representation.** Times are stored as `f64` seconds (`model.rs:107-108`; `time.rs:3-5`). `RationalTime` and `fps_tick_rate` are unused elsewhere in the crate.
- **Not every timeline mutation is journaled.** `append_media` extends the timeline and swaps media without `apply_edit` (`engine/media.rs:154-199`), yet its registry row is `mutating: true` (`tools.rs:1204-1206`), a flag documented as "lands undoable EditActions" (`tools.rs:34-36`).
- **File side effects are incomplete.** Missing: the frontier key fallback `<data dir>/roughcut/secrets/<key_ref>` (`mcp/client.rs:92-100`), the Resolve plugin scripts folder (`resolve.rs:31-35,71-78`), and temp files `roughcut-<media>.wav` (`engine/media.rs:49`) and `roughcut-resolve-<pid>.py` (`resolve.rs:126`).
- **Subprocesses and macOS services are incomplete.** Missing: the `security` CLI and Keychain (`mcp/client.rs:84-86,107-109`), `tar` (`llm_runtime.rs:163`), `which`, `sysctl`, and `df` (`llm_runtime.rs:36`, `transcribe.rs:66`, `capabilities.rs:71`, `record.rs:212`).
- **`ts-bindings` exports more than the model types.** It also exports `ProgressTask` (`events.rs:17-18`), the setup types (`setup.rs:18-55`), the Resolve types (`resolve.rs:18-19,82-83`), `MediaAssets`/`ThumbnailRef` (`adapters/video.rs:20-37`), and the recording types (`adapters/record.rs`).
- **Missing invariant: confirmation for external destructive ops.** `export`, `export_clip`, and `delete_project` from `McpClient` block on `request_confirmation` (`tools.rs:825-833,974-984,1001-1013`). This is enabled at bootstrap unless `ROUGHCUT_NO_CONFIRM=1` (`engine/mod.rs:125-128`).
- **Behaviour-changing env vars are not documented.** `FABLE_DEMO`, `ROUGHCUT_NO_CONFIRM`, `INFERENCE_ENDPOINT`, `INFERENCE_MODEL`, `EMBEDDING_MODEL`, `WHISPER_MODEL`, `FFMPEG_PATH`/`FFPROBE_PATH`, and `FRONTIER_MODEL`.
- **The `src` summary omits the `pty` and `resolve` modules** (`lib.rs:29-30`).

## core/src/README.md

- **The `model.rs` row omits public, ts-exported types.** Missing: `Aggressiveness` (`model.rs:560`), `ProjectSummary` (`model.rs:949`), `ModelTier` (`model.rs:569`), `CheckpointSummary` (`model.rs:816`), `HistoryEntry` (`model.rs:840`), and `ExternalConnection` (`model.rs:963`).
- **The `setup.rs` row omits the public `ModelTier` struct** (`setup.rs:190`), the element type of `MODEL_TIERS`, which has the same name as `model::ModelTier`.
- **The `ask_json_schema` fallback is imprecise.** The no-schema retry applies only on attempt 0 (`llm.rs:87`). The repair attempt sends `response_format` again (`llm.rs:62-68,84`), so a schema-rejecting server can make one call cost three requests and then fail hard (`llm.rs:92`).
- **"Every agent summary ends with a receipt" is false.** A `story_edit` that finalizes with zero actions returns its summary unchanged (`agent.rs:508-510`). A flow note is appended after the receipt (`agent.rs:355-359`).
- **Agent loop coverage gaps.** Missing: the model-backed `review_flow` and flow note after raw chat cuts (`agent.rs:327-343,456-458`), the cache clear after mutating rounds (`agent.rs:517-520`), and the 12-turn history limit (`agent.rs:243`).
- **"At most 3 review/repair rounds" is imprecise.** The limit is at most 3 reviews and at most 2 repairs (`story.rs:828,848-853,919`).
- **`story_edit` behaviour is omitted.** The README leaves out: silence cuts first (`story.rs:628-637`), the no-model fallback and error (`story.rs:593-622`), the refusal guardrails (`story.rs:712-749`), the contiguity guard (`story.rs:723-728`), and the trim to within 8% of the target (`story.rs:798-822`).
- **`clip_finder` windows are not always within one beat.** It falls back to cross-beat windows (`clip_finder.rs:96-100`). The themed `< 30` drop happens only if some judged candidate scores ≥ 30 (`clip_finder.rs:160-163`). The `count` and `min_s` clamps are undocumented (`clip_finder.rs:73-76`).
- **"Saves are upserts" does not cover embeddings.** `save_embeddings` deletes and re-inserts in a transaction (`store.rs:247-258`). The `open` migration (`ALTER TABLE … deleted_at`, `user_version = 1`) is undocumented (`store.rs:63-71`).
- **"Rename after verification" applies only to whisper models.** The llama-server and `.gguf` downloads pass `sha256: None` (`llm_runtime.rs:151-155,232-236`).
- **The Hugging Face fetch is attributed to the wrong module.** It is in `setup.rs` (`setup.rs:200-252`). `download.rs` is a generic downloader.
- **Side effects are incomplete.** Missing: `start_managed` writing `inference_endpoint` to preferences (`llm_runtime.rs:280-282`), the `bin/` extraction and `chmod 0755` (`llm_runtime.rs:144-196`), the Resolve temp script (`resolve.rs:126-141`), the GitHub API lookup and sidecar health polling, and embedding-endpoint calls (`setup.rs:183-187`, `clip_finder.rs:117`).
- **The environment section is incomplete.** `EMBEDDING_MODEL` is also read by the serde default (`model.rs:591-597`). `pty::spawn` sets `TERM`, `ROUGHCUT_MCP_URL`, and `ROUGHCUT_MCP_TOKEN` and falls back to `/bin/zsh` (`pty.rs:61,69-73`).
- **The bindings step mentions only `model.rs`.** Ts-exported types also live in `events.rs`, `setup.rs`, and `resolve.rs`.
- **`doc_parity.rs` checks both directions.** It also fails on tools documented but not registered (`doc_parity.rs:30-35`).
- **The consumer list misses `core/examples/`.**

## core/examples/README.md

- **The `face_smoke` frame count is wrong.** It writes between 6 and 12 frames, not always 12 (`face_smoke.rs:25`, `face.rs:129`). It panics on `expect("frame size")` when `end <= start` (`face_smoke.rs:48`).
- **`face.rs` is not wholly macOS-gated.** Only the Vision `imp` is gated (`face.rs:33`). A non-macOS stub returns `Unavailable` (`face.rs:81-89`), so `face_smoke` compiles everywhere and panics at `expect("detect")` (`face_smoke.rs:35`).
- **`agent_live` sends HTTP requests even when the server is unhealthy.** It always sends the health probe (`agent.rs:189-190`) and the background embeddings POST from `transcribe` (`engine/media.rs:86-105`, `engine/semantic.rs:61-74`). A step-0 model error also falls back offline (`agent.rs:294-298`).
- **The `agent_live` endpoint comes from env vars, not saved preferences.** The in-memory store uses `Preferences::default()` (`store.rs:219-221`), so the endpoint is `INFERENCE_ENDPOINT` and embeddings use `EMBEDDING_MODEL` (`model.rs:595-610`).
- **The `render_declick`/`render_progress` network traffic is undocumented.** Background `clean_transcript` and `index_transcript` hit the inference endpoint (`engine/media.rs:86-105`, `agent.rs:743-747`). The temp WAV is written by `Editor::transcribe`, not `AutoTranscriber` (`engine/media.rs:49,61`).
- **Take numbering skips `take2`.** `resume` uses `takes.len() + 1 + 1` (`record.rs:579`), so `takes_smoke` leaves `-take1.mp4` and `-take3.mp4` while `status` reports `take == 2` (`record.rs:618`).
- **Display selection is not covered.** `screen_smoke` and `dual_smoke` take the first display and panic if there is none (`screen_smoke.rs:9`, `dual_smoke.rs:13`). There is no index-0 fallback.
- **The `llm_install` disk effects are simplified.** It extracts into `bin/llama-extract/` and then moves files (`llm_runtime.rs:144-191`). On early failure the archive and extract folder are left behind (`llm_runtime.rs:168-173,183`). It prints `installed:` even when it was already installed.

## core/src/adapters/README.md

- **The Overview overstates "three implementations".** Only `VideoEngine` and `Transcriber` have `Auto*` selectors (`video.rs:708`, `transcribe.rs:331`). `Embedder` has no `Auto*` and `InferenceClient` has no mock (`embed.rs:19,87`, `inference.rs:81`).
- **`FfmpegCli::probe` failure modes are undocumented.** It returns `NotFound` for a missing file (`video.rs:167-168`) and `InvalidArg("no video stream")`, which rejects audio-only files (`video.rs:180-183`). It falls back to 30 fps and 48 kHz (`video.rs:185,197-200`).
- **`OllamaEmbedder` has no timeouts.** It uses `reqwest::Client::new()` (`embed.rs:30,52-58`), but the README implies bounded calls.
- **`healthy()` never sends the API key** (`inference.rs:130-138`, unlike `chat` at `109-111`). A key-protected remote endpoint therefore reports unhealthy.
- **Missing hazard: a dead capture's take can be discarded.** When ffmpeg already exited non-zero, `pause` and `stop` drop the take (`record.rs:437-439,556,679-683`), whereas `status()` would have kept it (`record.rs:640-653`).
- **Missing hazard: capture outputs are opened without `-y`** (`record.rs:325-405`). A repeated take path (after a failed finalize, `record.rs:579`, or a same-second session start, `record.rs:488`) can leave ffmpeg waiting at its overwrite prompt while `status()` reports recording.
- **Concat is not `-f avfoundation`.** It is `ffmpeg -f concat -safe 0 … -c copy` (`record.rs:729-738`).
- **`~/Movies/RoughCut` is created only by `start_capture_full`** (`record.rs:479`). `combine_recordings` doesn't create it and accepts inputs from outside it (`record.rs:812-845`).
- **The environment list omits `HOME`** (via `dirs`, `record.rs:232`, `store.rs:102-105`) **and `TMPDIR`** (`record.rs:720`).

## core/src/engine/README.md

- **The confirmation scope is wrong.** Only `ActionSource::McpClient` triggers `request_confirmation` (`tools.rs:824-827,974-976,1003-1006`). The local agent is never asked, despite README "MCP clients or the agent".
- **Not every suggestion change sends `TimelineChanged`.** Only `remove_suggestions` does (`edits.rs:302`). `generate_rough_cut` stores suggestions after its event (`edits.rs:207,222-229`). `jump_to` clears them after its last event (`edits.rs:509-519`), and `transcribe` sends only `TranscriptChanged` (`media.rs:72-81`).
- **`dismiss_suggestion` on an uncached project still sends `TimelineChanged`** (`edits.rs:296-303`). An unknown id returns `Ok(())`, not `NotFound`.
- **Missing caveat: `import_media` and `append_media` keep the undo journal and checkpoints** (`media.rs:18-31,170-189`). An undo or restore afterwards brings back clips built for the earlier media. `import_media` also keeps the old transcript and suggestions.
- **The temp WAV can leak.** If `extract_audio_wav` fails, the early return skips removal (`media.rs:55,60-61`).
- **`cut_confirmed_silences` silently drops failed per-silence edits** (`edits.rs:175-181`).
- **The environment section omits `FABLE_DEMO`.** It is read through `capabilities::probe()` by `demo_mode()` (`mod.rs:150-154`, `capabilities.rs:34`).
- **"Implements every operation" overstates the engine.** `export`, `export_clip`, and `snapshot` are `impl Editor` in `core/src/export/mod.rs:82-140`.
- **The dependency list omits `core/src/error.rs`**, which every engine file imports.

## core/src/export/README.md

- **The clip rename does not reach every target.** Only the NLE writers read `project.name` (`xmeml.rs:12`, `fcpxml.rs:22`, `edl.rs:13`, `otio.rs:19,34`). SRT, TXT, and MP4 are unaffected (`srt.rs:12-34`, `txt.rs:7-32`, `adapters/video.rs:47-56`).
- **The xmeml screen track can be missing even with `screen_media` set.** It is emitted only when `screen_items` is non-empty (`xmeml.rs:102,132-137`).
- **The EDL event line is not literally `AX  AA/V  C`.** The real format has more spacing and a second `* FROM CLIP NAME:` line that carries the clip name (`edl.rs:22`).
- **Not every FCPXML time is `{frames*den}/{num}s`.** The asset `start` is hard-coded `0s` (`fcpxml.rs:45`).
- **`clips_from_several_pieces_in_either_format` asserts `events >= 2`, not exactly one event per piece** (`tests/e2e.rs:1211-1212`).
- **`generate_captions` bypasses routing.** It skips `require_media`, so it produces SRT for a project with no media. Without a transcript it fails with `"no transcript"` rather than `"no transcript; transcribe first"` (`tools.rs:816-820`).

## core/src/mcp/README.md

- **Shim discovery is incomplete.** `--endpoint/--token` args, then `ROUGHCUT_MCP_ENDPOINT`/`ROUGHCUT_MCP_TOKEN`, pin the endpoint before `mcp.json` is read. The file path re-discovers up to 5 times, 700 ms apart (`mcp-shim/src/main.rs:36-47,92-134`). The shim's header comment ("NEW random port each launch", `main.rs:7`) contradicts `server.rs:40-52`.
- **A second consumer of the endpoint and token is undocumented.** `pty::spawn` exports `ROUGHCUT_MCP_URL`/`ROUGHCUT_MCP_TOKEN` into terminal shells (`app/src-tauri/src/lib.rs:254-255`, `pty.rs:70-72`). The README also omits `mcp_endpoint_info` and the `mcp-ready` event (`lib.rs:42-43,304`). The URL variable name differs from the shim's `ROUGHCUT_MCP_ENDPOINT`.
- **`McpClient`-gated behaviour is omitted.** It covers confirmation for `export`, `export_clip`, and `delete_project`, with a 120 s timeout (`tools.rs:825-833,974-984,1001-1011`; `engine/confirm.rs:23`), and the loopback-only `inference_endpoint` rule (`engine/projects.rs:220-229`).
- **"Auth comes first" is incomplete.** Axum's `Json` extractor runs before `authorized` (`server.rs:84,86`). A missing or wrong content type gets 415 and malformed JSON gets 400, both before auth.
- **Non-object bodies are treated as notifications.** `req.get("id")` is `None` for arrays and scalars (`server.rs:93,97`), so a JSON-RPC batch gets 202 `{}` and is dropped.
- **The protocol-version fallback also applies to non-string values** (`server.rs:103-104`).
- **The `escalate_to_frontier` error table is incomplete.** It omits `InvalidArg` on bad stored JSON (`client.rs:44`) and the unknown-provider error raised only after the secret loads (`client.rs:48-49,73-75`). `connect_external` never validates the provider (`client.rs:13-29`).
- **`load_secret` does not fall back to the file when `security` can't be spawned** (`client.rs:107-109`).
- **`0o600` is applied after the write** (`client.rs:95-99`), so the secret briefly has default permissions.
- **The `mcp.json` path contract breaks without an OS data dir.** `store::data_dir()` falls back to `./roughcut` (`store.rs:102-106`), while the shim errors (`main.rs:44-45`).
- **"<data dir>" is used two ways.** Secrets live at `dirs::data_dir()/roughcut/secrets/<key_ref>` (`client.rs:92,114`).
